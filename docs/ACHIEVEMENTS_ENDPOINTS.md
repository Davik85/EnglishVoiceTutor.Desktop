# Achievements endpoint

`GET /api/me/achievements` requires authentication and calculates Achievements V1 on request from all qualifying lesson sessions owned by the current user. It does not use Lesson History's `Take(50)` result.

A qualifying session has `Status == Finished` and a non-null `FinishedAt`. Streak dates use UTC. Account-wide streak and lesson-count achievements use every qualifying session; subtopic and finite-topic achievements use only sessions matching the current backend `UserSettings.StudyLanguage`, using the existing language normalizer.

`LessonContentId` is the canonical frozen scenario identity. Numeric topic/subtopic IDs and titles are never achievement identities. The five V1 topic definitions freeze these lists: Daily Life (`everyday_english_introductions`, `everyday_english_small_talk_with_a_neighbor`, `everyday_english_asking_for_help`, `everyday_english_making_plans`, `everyday_english_talking_about_your_day`); Travel (`travel_airport_check_in`, `travel_hotel_check_in`, `travel_asking_for_directions`, `travel_ordering_transport`, `travel_lost_luggage`); Work & Business (`work_business_first_meeting`, `work_business_daily_standup`, `work_business_phone_call_with_a_client`, `work_business_asking_for_clarification`, `work_business_discussing_deadlines`); Job Interview (`job_interview_tell_me_about_yourself`, `job_interview_work_experience`, `job_interview_strengths_and_weaknesses`, `job_interview_why_do_you_want_this_job`, `job_interview_asking_questions_at_the_end`); Restaurant & Cafe (`restaurant_and_cafe_booking_a_table`, `restaurant_and_cafe_ordering_food`, `restaurant_and_cafe_asking_about_ingredients`, `restaurant_and_cafe_handling_a_wrong_order`, `restaurant_and_cafe_paying_the_bill`). Free Conversation is excluded.

The response contains all applicable definitions, derived unlock state/dates/progress, and exactly three complete backend-selected Home items. Recent unlocks are selected first; locked fills use normalized remaining progress, fixed category order, then definition ID. There are no schema changes, migrations, persisted award rows, or background jobs. V1 intentionally follows the current Progress completion rule, including its legacy-data limitations.
